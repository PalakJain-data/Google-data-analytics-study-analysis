# Google Data Analytics Certification – Study & Progress Analysis

## 📊 Project Overview

This project analyzes my personal study records collected during the **Google Data Analytics Professional Certificate**.

The analysis was performed using **Microsoft Excel** to identify patterns in study time, course progress, study sessions, and college attendance status.

## 🎯 Project Objectives

The main objectives of this project were to:

* Analyze my recorded study activity.
* Understand weekly study-time patterns.
* Track my progress through the certification.
* Compare study time across college attendance statuses.
* Identify useful patterns and insights from the data.

## 📁 Dataset

The dataset contains my recorded study sessions during the certification period, along with course and college attendance information.

### Main Data Fields

* Date
* Day
* Study Hours
* College Attendance Status
* Course Number
* Course Name
* Coursera Estimated Time
* Module Number

## 🧹 Data Cleaning

The raw data was reviewed and organized in a separate **Cleaned Data** sheet before analysis.

The cleaning process included:

* Standardizing date and day fields.
* Formatting study-duration values consistently as time.
* Organizing course numbers, course names, and module information.
* Standardizing attendance categories such as **Present, Absent, and Holiday**.
* Reviewing missing study-duration records without assigning arbitrary values.

## 🔎 Analysis Performed

The cleaned dataset was analyzed in Microsoft Excel to answer five key questions:

1. What was my overall study activity during the certification?
2. Which courses had the highest and lowest recorded study time?
3. How did my study pattern change throughout the certification?
4. How did my course/module progress change over time?
5. How did recorded study time differ across college attendance statuses?

Excel functions and techniques used included:

* `SUM`
* `COUNT`
* `COUNTA`
* `AVERAGE`
* `MAX`
* `MIN`
* `SUMIFS`
* Conditional formatting
* Excel charts
* Basic data grouping and comparison

## 📈 Dashboard

The final dashboard summarizes the main findings using:

* Total recorded study time
* Total study records
* Courses completed
* Coursera estimated total hours
* Weekly study-time trend
* Course progress over time
* Study time by college attendance status
* Key insights

The dashboard is available as **[Dashboard.png](Dashboard.png)**.

## 💡 Key Insights

* Recorded study time peaked during **Week 2** at approximately **24 hours 24 minutes**.
* Study time decreased during the later weeks of the certification.
* Course progress increased from **Course 3 in Week 1 to Course 9 by Week 5**.
* Recorded study time was highest on **holidays**, followed by present and absent college days.
